# Lazur

## Запуск

Нужен Python 3.10+. В Windows запустите `src/LabCheker/start_demo.cmd` и откройте
http://127.0.0.1:8000. При первом запуске устанавливаются зависимости.
Остановка сервера — `Ctrl+C`.

Либо из папки `src/LabCheker`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-demo.txt
.\.venv\Scripts\python.exe -m uvicorn skeleton.main:app
```

## Готово

- Форма ввода кода и загрузка `.cs`/`.txt` в UTF-8 до 128 КБ.
- Страницы ожидания и результата с автообновлением статуса.
- Обработка ошибок ввода и экранирование HTML.
- Сохранение запросов и результатов между перезапусками.

Критерии задаются на сервере. Обработка пока возвращает тестовые данные;
подключение модели и сквозная проверка с backend — следующий этап.
