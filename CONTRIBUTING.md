# Правила работы в репозитории

Здесь описаны базовые рпавила работы в репозитории во избежание ппроблем с проектом. Данные правила относятся в основном к разработке (аналитика и документирование выполняется отдельно).
* Ветка main всегда рабочая, прямых коммитов в неё не делаем.
* Работа идёт в ветках вида feature/<номер задачи>-кратко.
* Слияние проводим через Pull Request (PR) минимум с одним ревьюером.
* Коммиты пишем осмысленные, не «fix» или «123».
